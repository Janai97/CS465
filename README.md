# Travlr Getaways - Full-Stack Travel Application

A full-stack travel booking application built using the MEAN stack, featuring robust RESTful APIs and a dynamic client-server architecture.

## 🛠️ Tech Stack
* **Frontend:** Angular, TypeScript, HTML5, CSS3
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Tools:** REST APIs, Git, GitHub

## ✨ Key Features
* **RESTful API Architecture:** Developed custom backend endpoints using Express.js and Node.js to handle data exchange.
* **Dynamic Frontend Interface:** Built a responsive single-page application experience using Angular components.
* **Flexible NoSQL Schema:** Designed MongoDB data models to store and manage travel packages and user information seamlessly.
